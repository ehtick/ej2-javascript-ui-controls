# OpenSpec Tasks Directory

This directory stores task breakdowns generated by PlannerAgent during the Tasks stage.

## File Naming Convention

```
tasks/
├── TASK-001-sorting-null-fix.md
├── TASK-002-virtual-scroll-grouping.md
└── ...
```

## Task File Format

```
Task ID: TASK-NNN
Title: [Short description]
Type: Bug Fix | New Feature | Improvement | Accessibility | Testing
Feature: [feature name from features_index]
Risk Level: critical | high | medium | low
Status: pending | in-progress | completed | failed

Description:
  [Detailed task description]

Files to Modify:
  - src/grid/actions/[feature].ts (lines X-Y)
  - spec/grid/[feature].spec.ts

Skills to Load:
  - [skill list]

Specs to Load:
  - [spec list]

Test Scenarios:
  1. [scenario]
  2. [scenario]

Acceptance Criteria:
  - [ ] All existing tests pass
  - [ ] New tests added (min 90% coverage)
  - [ ] No public API changes
  - [ ] Accessibility compliance verified
  - [ ] CHANGELOG.md updated
```

## Active Tasks

Tasks are created per development session. No active tasks at system initialization.
