## 🚀 Quick Start Guide

### For New Developers
1. Start with **[Training: 00-START-HERE](./training/00-START-HERE.md)**
2. Read **[Product Overview](./overview/product-overview.md)**
3. Set up your environment using **[Environment Setup](./tech-stack/environment-setup.md)**
4. Review **[Coding Standards](./code-guidelines/coding-standards.md)**

### For Feature Development
1. Review **[Development Workflow](./dev-process/development-workflow.md)**
2. Create feature specification in **[requirements/features/](./requirements/features/)**
3. Follow **[Coding Standards](./code-guidelines/coding-standards.md)**
4. Submit PR using **[PR Guidelines](./dev-process/pr-guidelines.md)**

### For Bug Fixes
1. Create bug analysis in **[requirements/bugs/](./requirements/bugs/)**
2. Review **[Error Handling](./code-guidelines/error-handling.md)**
3. Follow **[Branching Strategy](./dev-process/branching-strategy.md)**
4. Submit PR with root cause analysis

### For AI Agents
1. Read **[Agents Overview](./ai-agents/agents-overview.md)**
2. Follow **[Usage Guidelines](./ai-agents/usage-guidelines.md)**
3. Use request templates for specific tasks
